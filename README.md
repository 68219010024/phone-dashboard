# แดชบอร์ดแนวโน้มการใช้โทรศัพท์มือถือทั่วโลก (Streamlit)
บัญชีทดสอบ: judge / phone2025

รันบนเครื่อง:
```
cd dashboard
pip install -r requirements.txt
streamlit run app.py
```
นำขึ้นออนไลน์: อัปโหลดไฟล์ทั้งหมดในโฟลเดอร์นี้ขึ้น GitHub (app.py อยู่ชั้นนอกสุด) แล้วสร้างแอปที่ share.streamlit.io
Secrets:
```
[users]
judge = "phone2025"
```
หน้า: ภาพรวม · แบรนด์และระบบปฏิบัติการ · การเข้าถึงและราคา · เปรียบเทียบ · ผลการวิเคราะห์ · ข้อมูลและคู่มือ
